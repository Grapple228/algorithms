# Hash Tables (Хеш-таблицы)

## 🎯 Когда использовать

- Когда нужен O(1) доступ к элементам по ключу
- Для подсчёта частот элементов
- Для проверки существования элемента
- Для группировки элементов по какому-либо признаку

## 📊 Сложность

| Операция | Время  | Память |
| -------- | ------ | ------ |
| Вставка  | O(1)\* | O(n)   |
| Поиск    | O(1)\* | -      |
| Удаление | O(1)\* | -      |

\*В среднем случае, O(n) в худшем

## 🛠️ Типичные применения в задачах

1. **Two Sum** - хранение дополнений чисел
2. **Группировка анаграмм** - сортированная строка как ключ
3. **Поиск дубликатов** - проверка наличия в HashSet
4. **Подсчёт частот** - для Top K Frequent Elements

## 💡 Заметки

- В Rust: `HashMap<K, V>` для пар ключ-значение, `HashSet<T>` для уникальных значений
- Выбор хорошей хеш-функции важен для производительности
- Коллизии решаются цепочками или открытой адресацией
